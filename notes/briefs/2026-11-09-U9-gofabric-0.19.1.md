## 3. Host counters (new; owner decision 2026-11-09)

A host has counters a scraper wants beside the health — go-ha2fabric's
`discards` (commands a row answered with success and acted on nothing).
Shape, parallel to `Options.Warnings`/`Warning` (`fabricui/options.go:268-273`,
`handlers_node.go:70-72,153-156`, `HostWarnings.svelte`):

- `Options.Counters func(ctx context.Context) []Counter`;
  `Counter{Code string; Value uint64; Message string}` — `Code` the stable
  machine name (`discards`), `Message` the host's one-line meaning in the
  host's language.
- `Status.counters`: array of `Counter` (`code`, `value`, `message`),
  absent without `Options.Counters`, empty when the host reports none;
  also on `GET /nodes/{node}/status` as warnings are. Contract 0.8.0 note
  "(0.8.0)" in the description, as `admin` and `node_registry` carry theirs.
- Node Status page: a small table (code, value, message) under the
  warnings block, hidden when absent; live status refresh includes it as
  warnings are refreshed. i18n `de.json`/`en.json` for the heading only;
  codes and messages are the host's and are shown verbatim.
- Fixture `node-status.200.json` gains one counter; tests on both sides.
